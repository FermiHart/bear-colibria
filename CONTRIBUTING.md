# CONTRIBUTING — evidence first

1. Every behavioral claim ships with a frozen plan, one data attempt, and a
   replay-exact audit. Execution success is not predictive success.
2. Negatives are reported with the same weight as positives. A failed gate
   closes with HOLD, never with a relaxed gate.
3. No silent imputation, no target clipping, no post-hoc selection. Anything
   the model saw is declared.
4. Single language per artifact (this repo is English). No logs, keys,
   datasets, or personal paths in any submission.
